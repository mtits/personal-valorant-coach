Why this page exists

The published stats page is static and world-readable, so a Gemini key placed in it would be a key given away. This encrypts your key under a passphrase. The published file then holds only ciphertext, and the Coach tab asks for the passphrase before it can talk to Gemini.

This page is pure client-side cryptography — it works served from anywhere, including this public site. Everything you type stays in this tab; nothing is sent anywhere, and this page holds no key of its own.

Be clear about what this protects. Anyone can download the published file and guess passphrases offline as fast as their hardware allows. The security here is the passphrase. A word from any language is not enough — use a phrase. Nothing you type here leaves this page.
